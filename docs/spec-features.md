# Adrastea 機能仕様書

ブラウザベースのTRPGオンラインセッション向け盤面共有ツール。リアルタイムマップ・駒・シーン・チャット・BGM・カットインなど、セッション運営に必要な機能を統合。

---

## 1. シーン管理
シーンはセッションの背景・前景・シーンオブジェクト・BGMを切り替えるための単位。

### 作成・削除・複製
新規シーン追加時、デフォルト名「新規シーン」で自動作成。
既存シーン複製時は全オブジェクトが複製される。
削除時、そのシーンに属するオブジェクトは全て削除確認ダイアログが表示。キャラクター（駒含む）はルーム依存のためシーン削除の影響を受けない。
1つ以上のシーンは必須のため、最後のシーン削除は不可。

### シーン切替
アクティブシーン切替時、背景・前景の遷移効果（フェードイン）と遷移時間を適用。
BGMの遷移効果（フェードイン）も適用。
設定はシーン毎に独立。
楽観的UI更新により、サーバー応答を待たずに画面即座に反映。
シーン切替時、デバウンス保存中の編集は自動フラッシュ。
プロパティパネルに前景/背景が表示されていた場合、遷移先シーンの同タイプオブジェクトに自動切替（remountなし）。シーンオブジェクト等それ以外のオブジェクトが表示されていた場合はプロパティをクリア。

### 名前編集
シーン一覧からシーン名のダブルクリック・右クリック「名前変更」でインライン編集。

### 並べ替え
ドラッグハンドルのドラッグ&ドロップで順序変更（@dnd-kit）。
複数シーン選択中は複数移動をサポート。

## 2. レイヤー・オブジェクト管理
ボード上の全要素（背景、前景、パネル画像、テキスト、キャラクター駒）を「レイヤー」として一元管理。
各レイヤーは表示/非表示・z順で制御。

### レイヤーの種類
背景：シーンの背景画像固定レイヤー。位置は常に最下行固定。
前景：シーン前景画像固定レイヤー。DnDで移動不可。
オブジェクト：画像・テキスト・透明パネルをボード上に配置。DnDで移動可能。
テキストオブジェクト：ボード上テキスト表示（フォント・サイズ・色・配置制御）。DnDで移動可能。
キャラクター：キャラクター駒の自動レイヤー（個別に非表示化可能）。キャラクターレイヤ自体はDnD不可だが、内部のキャラクターは内部でのみDnDで移動可能。
キャラクター、前景はDnD不可だが、他移動可能レイヤーを移動させてキャラクター、前景の上下に配置することは可能。

### 表示・非表示・ロック
各オブジェクトはアイコン操作で表示/非表示切替。
位置ロック（position_locked）で移動不可、サイズロック（size_locked）でリサイズ不可にできる。

### 並べ替え・z順
ドラッグ&ドロップで z_order（sort_order）を変更。z値は連続的に管理され、並べ替え競合時は sortGenerationRef で世代番号を付けて重複を防止。

### オブジェクト追加・複製・削除
background / foreground type は直接追加不可。
背景・前景の画像URLはレイヤーパネルの背景/前景レイヤー行から編集。
オブジェクトは「+」ボタンで追加。
複製後の名前は以下のルールで自動生成（BGM以外の全エンティティ共通）：
- 末尾が `(n)` 形式でない場合: `元の名前(2)` にする
- 末尾が `(n)` 形式の場合: `元の名前(n+1)` にする（例: `マップA(2)` → `マップA(3)`）

削除は Delete キー。削除時は確認ダイアログで誤操作防止。

### 選択状態
全パネル（シーン・レイヤー・キャラクター・BGM・テキストメモ）の選択は panelSelection で横断的に一元管理。あるパネルで選択すると他パネルの選択は自動的にクリアされる。選択管理パネル外（ボード、チャット等）をクリックすると選択解除。プロパティパネルは選択に影響しない（触っても解除されない）。

選択操作は全パネル共通:
- 通常クリック: 単一選択
- Ctrl/Cmd+クリック: トグル（追加/除外）
- Shift+クリック: 範囲選択
- チェックボックス（ハンドル横）: トグル
- パネル内空白クリック: 選択解除（プロパティ表示は維持）

### キーボードショートカット
グローバルで1箇所（useGlobalKeyboardShortcuts）にバインド。テキスト入力中はスキップ。panelSelection の対象パネルに応じてディスパッチ。

- Ctrl+C: 選択中アイテムをクリップボードにコピー
- Ctrl+D: 選択中アイテムを複製
- Delete: 選択中アイテムを削除（確認ダイアログ）
- Ctrl+V: クリップボード内容に応じて自動判別してペースト（usePasteHandler がグローバル処理）

各パネルは keyboardActionsRef に copy/duplicate/delete ハンドラを登録。

### コンテキストメニュー
全パネルで右クリックメニューを提供。以下の共通ルールに従う:

アイテム上の右クリック: そのアイテムが未選択なら単一選択に切り替え、選択済みならそのまま維持（複数選択を崩さない）。メニューのアクション対象は選択中のアイテム全体。

空白エリアの右クリック: メニューを表示し、選択中のアイテムがあればコピー・複製・削除が有効。「貼り付け」は常に有効。単一選択時のみ「名前変更」「シーン切り替え」等の単体操作も有効。

ペースト時の命名規則は複製と同じ generateDuplicateName を適用（BGM以外）。

## 3. キャラクター管理
プレイヤーキャラクター・NPC駒の統合管理。立ち絵管理、ボード配置、ステータス・パラメータ記録。

### 作成・編集・削除

キャラクターパネルの「+」で新規作成。キャラクター選択後、クリックでプロパティパネルで詳細編集可能。ダブルクリックでモーダルで詳細編集が可能。削除時は確認ダイアログ。キャラクターを削除すると、そのキャラクターに紐付いた駒（Piece）も自動削除。

### 立ち絵（CharacterImage）管理

各キャラには複数立ち絵（URL・ラベル）を保持。active_image_index で現在表示立ち絵を指定。立ち絵選択時、オブジェクト層の「characters_layer」が自動存在確保。

### ボード配置・駒（Piece）連携

キャラクター駒はPieceテーブルで管理。character_id でキャラクターと紐付け。ボード上で移動・リサイズ時、board_x / board_y 自動更新。キャラクターサイズ（size）変更時、ボード座標は足元基準（board_y は自動調整不要）。

### ステータス・パラメータ・メモ

各キャラは任意数のステータス（ラベル・値・最大値）とパラメータ（ラベル・値）を保持。秘密メモ（secret_memo）の表示制御は room.gm_can_see_secret_memo 設定で制御。

### 並べ替え・可視性制御

キャラクターパネルでドラッグ&ドロップで並べ替え。この順序はキャラクター一覧の表示順（所有・管理上の順序）であり、ボード上の駒の重ね順とは独立している。is_hidden_on_board で駒全非表示。

### チャットパレット

各キャラ毎の「チャットパレット」テンプレート text を保持。チャット送信時に、そのキャラクターに設定されているステータス・パラメーターのラベル名が変数として展開される。例: ステータスに「hp」を設定していれば `{hp}` が現在値に置換される。変数名はキャラクターごとに自由設定なので、定義されていない変数名はそのまま残る。

### ボード上の駒の表示順制御
レイヤーパネルはあくまで「表示順（z順）管理」が目的。キャラクターレイヤー内のドラッグ&ドロップで駒の重ね順を変更できる。キャラクターパネルの並び順とは独立して管理される。

## 4. BGM管理

シーン別・複数トラック同時再生対応。フェード付き自動再生。

### トラック作成・管理

BGMパネルの「+」で新規トラック追加。YouTube / 直接URL / Cloudflare R2アップロードの3方式対応。Dropbox・Google Drive 共有リンク自動正規化。各トラックは個別ボリューム・ループ設定。

### シーン割当・自動再生

各BGMトラックは scene_ids リスト で複数シーンに割当可能。auto_play_scene_ids で指定シーン切替時の自動再生設定。同一シーン内複数トラック同時再生をサポート。

### 再生・停止・フェード

再生/停止ボタン、またはシーン切替時自動制御。fade_in / fade_in_duration で入場フェード。scene 切替時に前シーンBGMは自動停止、新シーン対象BGMは自動再生。

### ボリューム制御

トラック個別ボリューム（0～1）、全体マスターボリューム（localStorage 保存）。ミュート機能で全BGM消音。OBS風ボリュームフェーダーUI。

### エンジン・ストリーム管理

BgmEngine.tsx でWeb Audio API 管理。orphan トラック（どのシーンにも属さないトラック）はルーム入室時に自動検出・削除。シーン削除によって新たに orphan が発生した場合も即時削除する。シーン切替時の setTimeout は sceneTimersRef で管理、cleanup で漏洩防止。

## 5. チャット

リアルタイム メッセージ・ダイスロール・マークアップ対応。チャンネル分割。

### メッセージ送信・表示

ChatInputPanel で送信。sender_name / sender_uid / sender_avatar（URL）を記録。message_type は 'chat' / 'dice' / 'system'。senderName は localStorage で前回使用者保存。

チャットログ表示時、マークアップ処理：
- **太字**
- *イタリック*
- ~~打消し~~
- <color=#ff0000>色付き</color>

### ダイスロール

チャットを BCDice API（`https://bcdice.onlinesession.app/v2/game_system/{system}/roll`）に送信して結果を取得。結果を「ダイスロール」タイプ message として送信。ゲームシステムはルーム設定の dice_system を使用（デフォルト: DiceBot）。

BCDice API 送信前に、チャットパレットのテンプレート変数（`{ラベル名}`）を送信者キャラクターのステータス・パラメーター値で展開する。キャラクター未選択時は展開せずそのまま送信（BCDice が解釈できなければ通常チャットとして送信）。

秘密ダイス（BCDice の `secret` フラグ）に対応。秘密ダイス時は2つのメッセージを送信する。全員向けに「シークレットダイス」通知（送信者名・アバター付きで誰が振ったかは分かる）と、送信者のみに表示されるダイス結果（allowed_user_ids で制限）。送信者のみに表示される結果メッセージには「オープン」ボタンが表示され、押すと allowed_user_ids が解除されて全員にダイス結果が公開される。

### チャンネル

デフォルトチャンネルは「メイン」「情報」「雑談」の3つ（UI定数として固定）。ユーザーがカスタムチャンネルを追加可能。channel_id で message 紐付け。allowed_user_ids で表示制限（共有範囲制御）。

### 展開ボタン

チャット入力欄下部の「展開」アイコン（Maximize2）で全画面エディタ表示。テキスト同期。

### スクロール・履歴

チャットログは最新200件を初期表示。上端までスクロールすると IntersectionObserver で自動検知し、D1 Worker API から過去ログを追加取得（1回200件）。取得中はスクロール位置を保持。

## 7. シナリオテキスト

GM台詞・ナレーション・地の文テキスト表示。チャットパレット連携。

### 作成・編集・削除

ScenarioTextPanel で管理。「+」で新規追加。ScenarioTextEditor ダイアログで編集。title / content / speaker_character_id / channel_id を設定。削除は確認ダイアログ。

### チャンネル割当・チャット送信

channel_id でチャットチャンネル紐付け。「チャットに送信」ボタンで content をメッセージ送信。speaker_character_id で話者キャラ指定時は、そのキャラ名・アバターで送信。

### 表示制御・テンプレート

visible 切替で表示/非表示。テンプレート変数展開未対応（直接テキスト編集）。

### 並べ替え

ドラッグ&ドロップで sort_order 変更。

## 8. プロパティパネル

各エンティティ（シーン・オブジェクト・キャラクター・BGM・カットイン等）の詳細編集UI。PropertyDockPanel でパネル化。

### 背景プロパティ

背景画像（AssetPicker）・グリッド表示・背景ぼかし・背景フェードイン（有効/無効 + duration ms）を編集。

### 前景プロパティ

前景画像（AssetPicker）・画像表示モード（全体表示/トリミング/引き伸ばし）・位置(x/y)・サイズ(width/height)・位置ロック/サイズロック・前景フェードイン（有効/無効 + duration ms）を編集。

### オブジェクトプロパティ

選択オブジェクト（複数可）の name / x / y / width / height / visible / opacity / position_locked / size_locked / z_order（sort_order）を編集。

panel type：image_url / background_color / image_fit（contain/cover/stretch）。

text type：text_content / font_size / font_family / letter_spacing / line_height / auto_size / text_align / text_vertical_align / text_color / scale_x / scale_y。

### キャラクタープロパティ

name / color / size / initiative / sheet_url（キャラシートリンク）/ 各種ステータス・パラメータ / チャットパレット / 秘密メモ等を編集。

### BGM プロパティ

シーン切替時の自動再生・ループ・フェードイン（有効/無効 + duration ms）を編集。name は read-only 表示のみ。BGMの追加はアセットライブラリから行う。

### テキストメモ（シナリオテキスト）プロパティ

タイトル・本文（テキストエリア、拡大表示可）・話者キャラクター（キャラクター一覧から選択）・話者名（手入力、キャラクター選択時は自動補完）・チャンネル割り当てを編集。

### カットインプロパティ

name / image_url / text / animation / duration / text_color / background_color を編集。

### 操作UI

各プロパティ値は、フォーム要素（input / textarea / slider / color picker 等）で編集。変更はデバウンスで自動保存。キャラクターのみ明示的な「保存」ボタンあり（未保存時はハイライト表示）。

## 9. クリップボード入出力

Ctrl+C / Ctrl+V / Ctrl+D でオブジェクト・シーン複製・コピペ。

### オブジェクトコピー

選択オブジェクト複数個を JSON形式 でクリップボード保存。format：objectToClipboardJson() で統一。

clipboard JSON：
```
{
  "version": "1.0",
  "objects": [
    { "type": "panel", "name": "...", "x": ..., "y": ..., ... },
    ...
  ]
}
```

### ペースト（Ctrl+V）

LayerPanel / Board で Ctrl+V 実行。clipboard JSON parse → 新規オブジェクト一括作成。座標は オフセット（board center 付近）を適用。

### 複製（Ctrl+D）

選択オブジェクト複数個を複製。複製後の名前は以下のルールで自動生成（BGM以外の全エンティティ共通）：
- 末尾が `(n)` 形式でない場合: `元の名前(2)` にする
- 末尾が `(n)` 形式の場合: `元の名前(n+1)` にする（例: `マップA(2)` → `マップA(3)`）

### 削除（Delete）

選択オブジェクト削除。background / foreground / characters_layer type は削除不可（ロック状態）。

### シーン複製

ScenePanel 右クリック「複製」で、シーン全体（配下オブジェクト含）複製。background / foreground も複製。ルームスコープのオブジェクト（シーンに属さず全シーン共通で表示されるもの）はシーンに属さないため複製対象外。

## 10. Undo / Redo

操作履歴ステート管理（useUndoRedo フック）。スタック上限あり。

### 対象操作

シーン作成・削除・更新・並べ替え。
オブジェクト作成・削除・移動・リサイズ・更新・並べ替え。
キャラクター作成・削除・並べ替え。
BGM作成・削除・更新。
カットイン作成・削除。
シナリオテキスト作成・削除。

### スタック管理

UndoRedoHandle で push / undo / redo 操作。スタック上限（デフォルト50アクション）に達するとOLD操作を破棄。

### UI操作

TopToolbar に「↶ Undo」「↷ Redo」ボタン（disable 状態は canUndo / canRedo で制御）。キーボードショートカット Ctrl+Z / Ctrl+Y でも実行。

## 11. 権限システム

ロールベース権限制御（RBAC）。ロール階層：guest < user < sub_owner < owner。

### ロール定義

guest：閲覧のみ。チャット送信・駒移動・キャラクター編集を含む全操作不可。見るだけ。

user：基本操作（駒移動・チャット・キャラ編集）。シーン・BGM・カットイン編集不可。

sub_owner：シーン・オブジェクト・BGM・カットイン・レイヤー編集可。ロール割当不可。

owner：全機能。ロール割当・ルーム設定変更可能。

### ロール変更UI

SettingsModal の「メンバー一覧」セクションでメンバーのロールを変更できる。owner のみ操作可能。owner 自身のロールは変更不可（「オーナーのロールは変更できません」と表示）。変更対象ロールは sub_owner / user / guest の3種。

### パーミッション定義

各操作に最低限必要ロール（PERMISSION_MIN_ROLE）を設定。

chat_send：user 以上
piece_move / object_move：user 以上
character_edit：user 以上
scene_edit / object_edit / bgm_manage / cutin_manage / layer_manage：sub_owner 以上
room_settings / role_assign：owner のみ
panel_*：各パネルに最低ロール設定（panel_debug は owner のみ）

### パネル表示制限

guest ログイン時、アクセス権限なしパネルは表示・入力不可。LayerPanel / ScenePanel / BgmPanel 等は sub_owner 権限要件のため guest は非表示。

### checkPermission()

withPermission()ラッパーで各操作にガード。権限不足時は toast error 表示で通知。

## 12. キーボードショートカット

ボード・パネル操作の高速化。

### ボード操作

Ctrl+Z：Undo
Ctrl+Y / Ctrl+Shift+Z：Redo
Delete：選択オブジェクト削除（確認ダイアログ）
Ctrl+C：選択オブジェクトコピー
Ctrl+V：ペースト
Ctrl+D：選択オブジェクト複製

### パネル操作

Ctrl+C（LayerPanel）：選択オブジェクト / シーン / キャラクター コピー
Ctrl+D（LayerPanel）：複製
Ctrl+V（LayerPanel）：ペースト

Delete（ScenePanel）：選択シーン削除（複数選択時も一括）
Delete（CharacterPanel）：選択キャラ削除

Delete（BgmPanel）：選択BGM削除
Delete（ScenarioTextPanel）：選択テキスト削除

Enter（ChatInputPanel）：メッセージ送信 / Shift+Enter：改行

### 条件付け

エディタ入力中（INPUT / TEXTAREA / contentEditable）の場合、ショートカット無効化。削除系操作は確認ダイアログ要求。

## 付録：データモデル関連

### Room

ID・オーナーID・名前・説明・アクティブシーンID・前景URL（全体）・アクティブカットイン・ダイスシステム・ロール・タイムスタンプ。

### Scene

ID・ルームID・名前・背景/前景URL・不透明度・遷移設定・ぼかし・ソート順。

### BoardObject

タイプ（panel / text / foreground / background / characters_layer）・グローバル/シーンスコープ・座標・サイズ・表示・opacity・ロック・z順・パネル固有（画像URL・背景色・fit）・テキスト固有（内容・フォント・色・配置）。

### Character

ID・ルームID・オーナーID・名前・立ち絵リスト・現在立ち絵INDEX・色・シートURL・イニシアチブ・サイズ・ステータス・パラメータ・メモ・秘密メモ・チャットパレット・可視性制御・ソート順・ボード座標。

### BgmTrack

ID・名前・タイプ（youtube/url/upload）・ソース・ボリューム・ループ・シーン割当・自動再生シーン・フェード設定・ソート順。

### ChatMessage

ID・ルームID・送信者名・送信者UID・送信者アバターURL・内容・メッセージタイプ・チャンネル・制限ユーザーID・タイムスタンプ。

### Cutin / ScenarioText

各々、ID・ルームID・名前・画像/テキスト・設定（アニメーション・色等）・ソート順・タイムスタンプ。

## 13. アニメーション画像の継続再生

アニメーション画像（GIF/WebP/APNG）はシーン遷移をまたいで再生を継続する。

DomObjectOverlay で `generateStableKeys` 関数を使い、`type + image_url + 座標の近接性（greedy matching）` で React の key を割り当て。key が同一の DOM はリマウントされないため、アニメーションが継続。sceneId は key に含めない（含めるとシーン切替でリマウントされてしまう）。

blobCache は refCount ベース管理で、シーン遷移後も即 revoke せず 200ms 遅延 revoke。blobCache は画像の Blob を保持（fetch 省略 & メモリ管理）、表示用 blob URL はコンポーネントごとに毎回 `URL.createObjectURL` で新規生成し、unmount 時に revoke する。

## 14. BGM シーン遷移挙動

BgmEngine がシーン切替を検知し、前シーンの BGM を停止・新シーンの BGM を開始する。

activeScene?.id 変更をトリガーに tracksToStop（前シーンのみ対象）と tracksToStart（auto_play_scene_ids が新シーンを含む）を抽出。tracksToStart のフェードイン時間の最大値（maxFadeInDuration）+ 100ms のタイマーで前シーン BGM を遅延停止（フェードの重なりを確保）。

フェードイン設定がある場合は fade_in_duration でボリュームを徐々に上げる。orphan トラック（scene_ids.length === 0）は即時停止。タイマーは sceneTimersRef で管理し、useEffect cleanup で漏洩防止。

## 15. サムネイル表示

シーンパネル・キャラクターパネルで各エンティティのサムネイルを表示。

### シーンサムネイル

高さ 40px。background_url と foreground_url を斜め分割して 2 つの画像を並べて表示。どちらかが未設定の場合は設定済みの画像のみ、または空表示。

### キャラクターサムネイル

40×40px。images[active_image_index].url を cover fit・上寄せで表示。立ち絵未設定時はプレースホルダー表示。

---

## 16. ステータスパネル

全キャラクターのステータス・イニシアチブを一覧表示するパネル。StatusDockPanel として dockview に登録。

### 表示内容

キャラクター一覧をイニシアチブ値（initiative）降順でソートして表示。各キャラクターのステータス値を StatusBar コンポーネントで表示。

### 操作

各ステータスバーは▲▼ボタンで値を増減。右クリックしたままドラッグで値を連続編集（マウス操作による直感的な増減）。

### プライベート設定

is_status_private が true のキャラクターのステータスは「?」として表示（owner のみ実値確認可）。

---

## 17. チャットパレットパネル

キャラクターごとのチャットパレットを一覧表示し、テンプレートを素早く送信するパネル。ChatPaletteDockPanel として dockview に登録。

### 表示内容

各キャラクターのチャットパレット（chat_palette フィールド）を改行区切りでボタン一覧として表示。

### 操作

各行の左アイコン（Send）クリック：そのテキストを resolveTemplateVars でキャラクターのステータス・パラメーター値に変数展開して即チャット送信。

各行の右テキスト部分クリック：テキストをチャット入力欄に挿入（送信前に編集可能）。

---

## 18. チャット入力パネルのサジェスト

チャット入力中にチャットパレットの候補をサジェスト表示。

入力中、全キャラクターの chat_palette 内容に対して部分一致で候補をリアルタイム検索。サジェストリストはカーソル位置（入力中の行）を基準にオーバーレイ表示。IME 入力中（変換中）はサジェストを更新しない。Arrow keys で候補ハイライト移動、Tab / Enter で選択・入力欄に反映。確定後はサジェストが閉じ、次の入力まで再表示しない。

---

## 19. アセットライブラリ

画像・音声ファイルを一元管理するモーダル。AssetLibraryModal として実装。

### タブ

画像タブ：画像ファイル一覧、アップロード・URL 入力・タグ付け・検索（名前/タグ）。

音声タブ：音声ファイル一覧、アップロード・URL 入力・YouTube URL 入力・タグ付け・検索（名前/タイトル/タグ）。

### アップロード方式

ファイルアップロード → Cloudflare R2 に保存。

URL 直接入力（Dropbox・Google Drive 共有リンクは自動正規化）。

YouTube URL 入力（音声タブのみ）。

### 検索・フィルタ

名前・タイトル・タグによる部分一致検索。

### タグ管理

各アセットにタグを複数付与可能。タグ一覧から一括絞り込み。

## ルームタグ

ルーム一覧画面でルームにタグ（文字列配列）を付与可能。Supabase rooms.tags (jsonb) に保存。同一アカウントの別端末でも同期される。タグはルーム検索・フィルタリングに使用。

## 20. PDF パネル

PDF 参照資料をブラウザ内で閲覧するパネル。PdfViewerDockPanel として dockview に登録。user 以上のロールで使用可能。

### 機能

ローカルファイル選択（ファイル選択ダイアログ）による PDF 読み込み。

ページネーション（前後ページ移動、ページ番号表示）。

ResizeObserver によるパネルサイズ変化への適応表示。

### 制限

サーバーへのアップロード・URL 入力はなし。ローカルファイルのみ。

セッションをまたいだ保存はなし（ページをリロードすると再選択が必要）。

## 22. チャットログパネルの詳細

ChatLogPanel の詳細機能。

### メッセージ種別と表示

chat：通常メッセージ。送信者名・アバター・テキスト表示。

dice：ダイスロール結果。成功は緑、失敗は赤でハイライト。

### ログ出力

チャットログを HTML 形式でエクスポート可能。

## 23. パネルレイアウト管理（dockview）

DockLayout.tsx で dockview ライブラリを使い、柔軟なパネル配置を実現。

### レイアウト保存

パネルの配置・サイズ変更を 300ms debounce で localStorage に自動保存。

ページリロード後もレイアウトを復元。

### パネル操作

フロート化：パネルヘッダーの PictureInPicture2 アイコンで独立ウィンドウとして切り離し。

最小化：パネルを折りたたみ表示。

ドッキング：フロートパネルをドラッグしてドックに戻す。

### デフォルトレイアウト

ロール（owner / sub_owner / user / guest）ごとに初期パネル配置を定義。

保存済みレイアウトがない初回アクセス時に適用。

### 幅制約

Board パネルは幅可変（残りスペースを占有）。

その他パネル（サイドバー系）は固定幅制約。

## 24. 複数選択・ドラッグ&ドロップ詳細

各パネルでの複数選択操作とドラッグ&ドロップの詳細仕様。

### 選択操作（全パネル共通）

単体クリック：単一選択。

Shift+クリック：範囲選択。

Ctrl+クリック：個別追加/解除（トグル）。

### ScenePanel

複数選択時、Delete で一括削除（確認ダイアログ）。

複数選択時、右クリック「複製」で一括複製。

### ObjectLayerList（レイヤーパネル内オブジェクト一覧）

複数オブジェクト選択状態でドラッグ：選択中の全オブジェクトを一括移動。

ドラッグ対象が未選択オブジェクトの場合：単一選択に切り替えてからドラッグ。

background：位置固定のため DnD 不可。

foreground：DnD 不可（z 順変更のための DnD は制限あり）。

characters_layer 内のキャラクター：内部でのみ DnD で並べ替え可能。

### CharacterPanel

複数選択時、Delete で一括削除。

ドラッグ&ドロップでキャラクター表示順を変更（ボード上の z 順とは独立）。

## UI 共通仕様: パネルヘッダーボタン

SortableListPanel を使用する全パネル（シーン・キャラクター・レイヤー・BGM・テキストメモ・カットイン）で、ヘッダー右端のアクションボタンを以下の仕様で統一する。

### ボタン構成

左から順に「複製」「削除」「追加」の3ボタンを配置する。パネルによっては一部省略可（例: BGMパネルの追加のみ）。

### スタイル仕様

ラッパー: `display: flex, alignItems: center, gap: 1px`

各ボタン共通: `background: transparent, border: none, cursor: pointer, padding: 2px 4px, display: flex, alignItems: center`

アイコンサイズ: 15px（lucide-react の size={15}）

色:
- 複製ボタン: `theme.textSecondary`（グレー）
- 削除ボタン: `theme.danger`（赤）
- 追加ボタン: `theme.accent`（青）

disabled 状態: `opacity: 0.3`, `cursor: default`

各ボタンに Tooltip を付与する（ラベル例: 「複製」「削除」「シーンを追加」）。

### 行内アクションボタンの方針

リスト各行にインラインの削除ボタンは配置しない。削除はヘッダーボタン・右クリックメニュー・Delete キーで行う。
行内に配置してよいのは、その行固有の操作（表示/非表示トグル、チャット送信など）のみ。

## 25. ルームデータアーカイブ・復元

### 自動アーカイブ
最終更新から30日経過したルームは自動的にアーカイブされる。
アーカイブされたルームの関連データ（シーン・オブジェクト・BGM・キャラクター等）はバックエンドストレージ（D1）に退避され、メインDB（Supabase Postgres）から削除される。
ルームのメタ情報（名前・ID・オーナー）はロビー一覧に残り、アーカイブ済みであることが表示される。

### 入室時の自動復元
アーカイブ済みルームに入室すると、自動的にデータ復元が開始される。
復元中は「ルームデータを復元中...」のローディング画面が表示される。
復元完了後、ページが自動リロードされ通常通りセッションに参加できる。
復元にかかる時間はデータ量に依存するが、通常数秒程度。

### アーカイブ対象外
アクティブなルーム（30日以内にアクセスあり）はアーカイブされない。
ルーム入室時に last_accessed_at が自動更新されるため、定期的に使用されているルームはアーカイブ対象にならない。

## 実装統括

Adrastea はマルチユーザーセッション運営に必要な全機能を1つのブラウザアプリで提供。Supabase（リアルタイムDB）で全データ管理・差分同期。Cloudflare R2/D1/Workers でアセット配信・チャットアーカイブ・ルームアーカイブを管理。権限層で各ロールの操作範囲を制御。キーボード主体UI で高速操作実現。
