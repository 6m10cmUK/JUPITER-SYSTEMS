# 0001: P2P廃止・Convex採用

## ステータス
廃止（2026-03）— 0003 で Supabase に移行

## コンテキスト
Adrastea のリアルタイム同期に WebRTC P2P を採用していたが、以下の問題で実用不可だった：
- ICE 接続不安定（mDNS + NAT ヘアピン問題）
- TURN サーバーなしでは NAT 越え不可
- TURN サーバーの運用コストが個人プロジェクトに見合わない

## 決定
P2P を廃止し、Convex をリアルタイムデータベース兼バックエンドとして採用する。

## 理由
- リアルタイム同期が組み込み（サブスクリプション）
- サーバー関数でバックエンドロジックも書ける
- 認証（Convex Auth）も統合可能
- 無料枠が個人プロジェクトに十分

## 結果
- D1 はチャットアーカイブ用に残存
- R2 はアセット配信用に変更なし
- Firebase Auth → Convex Auth に移行
