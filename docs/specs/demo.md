# デモページ

ログイン不要でAdrasteaの機能を体験できるデモ環境。DB接続・認証なし、ローカルステートのみで動作。タブを閉じるとリセット。

## ルーティング

- パス: `/adrastea-demo`
- ドキュメントタイトル: "Adrastea Demo"

## アーキテクチャ

- `MockAdrasteaProvider` が `AdrasteaContext` と同じインターフェースを提供
- `useMockAdrasteaState` フックでローカルステート管理
- 本番UIコンポーネントをそのまま流用（コンポーネント側の変更不要）
- `isDemo: true` フラグでデモ固有の制御を識別

## 初期データ

- ルーム: "Adrastea デモ"（ID: `demo-room-001`）
- ユーザー: "デモユーザー"（ID: `demo-user`、ロール: `owner`）
- シーン・オブジェクト・キャラクター・BGM: 空（初回マウント時にデフォルトシーン「メイン」を自動作成）
- チャンネル: `main` 1つのみ（固定）
- ダイスシステム: `DiceBot`
- マスターボリューム: 0.5

## 動作する機能

以下はローカルステートで完全に動作する。

- シーン: 作成・更新・削除・複製・並べ替え・切替
- オブジェクト: 作成・更新・移動・削除・並べ替え
- キャラクター: 作成・更新・移動・削除・並べ替え（レイヤー順序含む）
- BGM: 作成・更新・削除・並べ替え
- カットイン: 作成・更新・削除・トリガー・クリア
- チャット: メッセージ送信・表示
- シナリオテキスト: 作成・更新・削除・並べ替え
- ピース（駒）: 作成・更新・移動・削除
- プロパティ編集: 全エンティティ対応
- Undo / Redo: Ctrl+Z / Ctrl+Shift+Z
- クリップボード: シーン・BGM・キャラクター・オブジェクトのペースト
- グリッド表示切替
- ルーム設定変更（名前等）
- プロフィール編集
- パネルレイアウト（DockLayout）
- ボードのズーム・パン

## 動作しない機能（トースト通知で案内）

- ログアウト → "ログアウト機能はデモ環境では無効です"
- ルーム削除 → "デモ環境ではルーム削除はサポートされていません"
- メンバー管理・ロール割り当て → "デモ環境ではメンバー管理はサポートされていません"

## 動作しない機能（サイレント）

- チャンネル作成・削除（no-op）
- アセットアップロード（R2接続なし）
- リアルタイム同期（シングルユーザー固定）
- データ永続化（メモリのみ、リロードでリセット）

## 制約

- ユーザーは常に `demo-user`（owner権限）固定
- マルチユーザーのシミュレーションなし
- ファイルアップロード不可（外部ストレージ接続なし）
- メンバーリストは常に空配列

## 実装ファイル

- ページ: `src/pages/AdrasteaDemo.tsx`
- プロバイダー: `src/contexts/MockAdrasteaProvider.tsx`
- ステート管理: `src/hooks/useMockAdrasteaState.ts`
