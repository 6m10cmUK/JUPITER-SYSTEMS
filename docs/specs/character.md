# キャラクター管理

プレイヤーキャラクター・NPC駒の統合管理。立ち絵管理、ボード配置、ステータス・パラメータ記録。

## 作成・編集・削除

キャラクターパネルの「+」で新規作成。キャラクター選択後、クリックでプロパティパネルで詳細編集可能。ダブルクリックでモーダルで詳細編集が可能。削除時は確認ダイアログ。キャラクターを削除すると、そのキャラクターに紐付いた駒（Piece）も自動削除。

## 立ち絵（CharacterImage）管理

各キャラには複数立ち絵（URL・ラベル）を保持。active_image_index で現在表示立ち絵を指定。立ち絵選択時、オブジェクト層の「characters_layer」が自動存在確保。

## ボード配置・駒（Piece）連携

キャラクター駒はPieceテーブルで管理。character_id でキャラクターと紐付け。ボード上で移動・リサイズ時、board_x / board_y 自動更新。キャラクターサイズ（size）変更時、ボード座標は足元基準（board_y は自動調整不要）。

ボード上でキャラクター駒をドラッグすると board_x / board_y が即座に更新され、Supabase 経由でリアルタイム同期される。この操作は権限チェック不要（guest 含む全ロールで可能）。プロパティパネルが開いている場合、X/Y の値もリアルタイムで反映される。

## ステータス・パラメータ・メモ

各キャラは任意数のステータス（ラベル・値・最大値）とパラメータ（ラベル・値）を保持。秘密メモ（secret_memo）の表示制御は room.gm_can_see_secret_memo 設定で制御。

## 並べ替え・可視性制御

キャラクターパネルでドラッグ&ドロップで並べ替え。この順序はキャラクター一覧の表示順（所有・管理上の順序）であり、ボード上の駒の重ね順とは独立している。is_hidden_on_board で駒全非表示。

board_visible フラグでキャラクター駒のボード表示/非表示を切り替える。キャラクターパネルおよびレイヤーパネルの目アイコン（Eye/EyeOff）で操作。board_visible: false のキャラクターはボード上に描画されず、ステータスパネルにも表示されない。

## チャットパレット

各キャラ毎の「チャットパレット」テンプレート text を保持。チャット送信時に、そのキャラクターに設定されているステータス・パラメーターのラベル名が変数として展開される。例: ステータスに「hp」を設定していれば `{hp}` が現在値に置換される。変数名はキャラクターごとに自由設定なので、定義されていない変数名はそのまま残る。

## ボード上の駒の表示順制御

レイヤーパネルはあくまで「表示順（z順）管理」が目的。キャラクターレイヤー内のドラッグ&ドロップで駒の重ね順を変更できる。キャラクターパネルの並び順とは独立して管理される。

## キャラクター譲渡

キャラクターの所有権（owner_id）を同じルームの他メンバーに移譲できる。右クリックメニューの「譲渡」から譲渡先を選択する。譲渡モーダルにはルームメンバーのアバター・表示名・ロールが表示される（自分自身は除外）。譲渡は自分のキャラクターに対してのみ可能（sub_owner 以上は全キャラ操作可）。対応箇所はキャラクターパネル、ボード上キャラクター画像、レイヤーパネルの3箇所。
