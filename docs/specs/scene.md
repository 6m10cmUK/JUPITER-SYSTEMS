# シーン管理

シーンはセッションの背景・前景・シーンオブジェクト・BGMを切り替えるための単位。

## 作成・削除・複製

新規シーン追加時、デフォルト名「新規シーン」で自動作成。
既存シーン複製時は全オブジェクトが複製される。
削除時、そのシーンに属するオブジェクトは全て削除確認ダイアログが表示。キャラクター（駒含む）はルーム依存のためシーン削除の影響を受けない。
1つ以上のシーンは必須のため、最後のシーン削除は不可。

## シーン切替

アクティブシーン切替時、背景・前景の遷移効果（フェードイン）と遷移時間を適用。
BGMの遷移効果（フェードイン）も適用。
設定はシーン毎に独立。
楽観的UI更新により、サーバー応答を待たずに画面即座に反映。
シーン切替時、デバウンス保存中の編集は自動フラッシュ。
プロパティパネルに前景/背景が表示されていた場合、遷移先シーンの同タイプオブジェクトに自動切替（remountなし）。シーンオブジェクト等それ以外のオブジェクトが表示されていた場合はプロパティをクリア。

## 名前編集

シーン一覧からシーン名のダブルクリック・右クリック「名前変更」でインライン編集。

## 並べ替え

ドラッグハンドルのドラッグ&ドロップで順序変更（@dnd-kit）。
複数シーン選択中は複数移動をサポート。
