# ロビー画面

ルーム一覧・作成・管理、プロフィール設定を行うエントリーポイント。認証済みユーザーのみ表示。

## ルーム一覧

グリッドレイアウト（自動折り返し、最小200px）でルームカードを表示。
各カードにルーム名・ダイスシステム・タグバッジ・更新日付を表示。
アクションボタン: 共有（Share2）・編集（Pencil）・削除（X）。
カードクリックでルームに入室。

### 検索

ルーム名・タグ・ダイスシステム名で全文検索（128文字上限）。

### 並べ替え

@dnd-kit によるドラッグ&ドロップでルームカードの順序を変更。
並び順は localStorage（`adrastea-room-order`）に ID 配列で保存。
デフォルトは updated_at 降順。
検索中の並べ替えは絞り込み結果のみを対象にし、その他ルームの順序を保持。

## ルーム作成

「ルームを作成」カード（dashed border）クリックでモーダル表示。

入力項目:
- ルーム名（必須、trim チェック）
- ダイスシステム選択（DiceSystemPicker、全系統先読みキャッシュ）
- タグ入力（AdComboBox multi-mode、既存タグ提案）

作成時に自動生成されるデータ:
- rooms レコード
- room_members（owner ロールで自動登録）
- デフォルトシーン「メイン」
- background・foreground・characters_layer オブジェクト

## ルーム編集

ルームカードの編集ボタンでモーダル表示。ルーム名・ダイスシステム・タグを変更可能。

## ルーム削除

削除ボタン → 確認モーダル → archived: true の論理削除。ロビー一覧から非表示になる。

## ルーム共有

共有ボタンで `{origin}/adrastea/{roomId}` をクリップボードにコピー。

## ルームタグ

ルーム一覧画面でルームにタグ（文字列配列）を付与可能。Supabase rooms.tags (jsonb) に保存。同一アカウントの別端末でも同期される。タグはルーム検索・フィルタリングに使用。

## プロフィール

ヘッダー右上のアイコンからプロフィール編集モーダルを表示。

### 表示名

テキスト入力（最大30文字、自動trim、空文字不可）。

### アバター

AssetPicker でアセットライブラリから選択 or 新規アップロード。未設定時は表示名の頭文字を円形アイコンで表示。

### 保存先

Supabase auth.updateUser()（full_name, avatar_url）+ users テーブル（display_name, avatar_url, updated_at）。

## Onboarding

初回ログイン時（onboarded フラグが false）にプロフィール設定モーダルを全画面表示。表示名とアバターの設定を促す。スキップ可能。

## DebugConsole

Owner ロール専用の開発者パネル。console.log/warn/error と uncaught exceptions をリアルタイム表示。ログクリア・コピー・レベルフィルタ機能。dockview の DebugConsoleDockPanel として登録。

## ルーム設定モーダル

ルーム編集時に表示されるモーダル。ルーム名・ダイスシステム・タグ変更に加え、以下の機能を提供する。

### ルーム退出

ルーム設定モーダル内に「ルームから退出」ボタンを配置。クリックすると、自分自身を room_members から削除してロビー画面に戻る。所有者の場合、退出前に警告を表示する。

### デフォルトログインロール

ルーム設定でデフォルトログインロール（default_login_role）を owner のみ変更可能。新規ユーザーがルームに入室した際、この設定が自動適用される。
