# レイヤー・オブジェクト管理

ボード上の全要素（背景、前景、パネル画像、テキスト、キャラクター駒）を「レイヤー」として一元管理。
各レイヤーは表示/非表示・z順で制御。

## レイヤーの種類

背景：シーンの背景画像固定レイヤー。位置は常に最下行固定。
前景：シーン前景画像固定レイヤー。DnDで移動不可。
オブジェクト：画像・テキスト・透明パネルをボード上に配置。DnDで移動可能。
テキストオブジェクト：ボード上テキスト表示（フォント・サイズ・色・配置制御）。DnDで移動可能。
キャラクター：キャラクター駒の自動レイヤー（個別に非表示化可能）。キャラクターレイヤ自体はDnD不可だが、内部のキャラクターは内部でのみDnDで移動可能。
キャラクター、前景はDnD不可だが、他移動可能レイヤーを移動させてキャラクター、前景の上下に配置することは可能。

## 表示・非表示・ロック

各オブジェクトはアイコン操作で表示/非表示切替。
位置ロック（position_locked）で移動不可、サイズロック（size_locked）でリサイズ不可にできる。

## 並べ替え・z順

ドラッグ&ドロップで z_order（sort_order）を変更。z値は連続的に管理され、並べ替え競合時は sortGenerationRef で世代番号を付けて重複を防止。

## オブジェクト追加・複製・削除

background / foreground type は直接追加不可。
背景・前景の画像URLはレイヤーパネルの背景/前景レイヤー行から編集。
オブジェクトは「+」ボタンで追加。
複製後の名前は以下のルールで自動生成（BGM以外の全エンティティ共通）：
- 末尾が `(n)` 形式でない場合: `元の名前(2)` にする
- 末尾が `(n)` 形式の場合: `元の名前(n+1)` にする（例: `マップA(2)` → `マップA(3)`）

削除は Delete キー。削除時は確認ダイアログで誤操作防止。

## 選択状態

全パネル（シーン・レイヤー・キャラクター・BGM・テキストメモ）の選択は panelSelection で横断的に一元管理。あるパネルで選択すると他パネルの選択は自動的にクリアされる。選択管理パネル外（ボード、チャット等）をクリックすると選択解除。プロパティパネルは選択に影響しない（触っても解除されない）。

選択操作は全パネル共通:
- 通常クリック: 単一選択
- Ctrl/Cmd+クリック: トグル（追加/除外）
- Shift+クリック: 範囲選択
- チェックボックス（ハンドル横）: トグル
- パネル内空白クリック: 選択解除（プロパティ表示は維持）

## キーボードショートカット

グローバルで1箇所（useGlobalKeyboardShortcuts）にバインド。テキスト入力中はスキップ。panelSelection の対象パネルに応じてディスパッチ。

- Ctrl+C: 選択中アイテムをクリップボードにコピー
- Ctrl+D: 選択中アイテムを複製
- Delete: 選択中アイテムを削除（確認ダイアログ）
- Ctrl+V: クリップボード内容に応じて自動判別してペースト（usePasteHandler がグローバル処理）

各パネルは keyboardActionsRef に copy/duplicate/delete ハンドラを登録。

## コンテキストメニュー

全パネルで右クリックメニューを提供。以下の共通ルールに従う:

アイテム上の右クリック: そのアイテムが未選択なら単一選択に切り替え、選択済みならそのまま維持（複数選択を崩さない）。メニューのアクション対象は選択中のアイテム全体。

空白エリアの右クリック: メニューを表示し、選択中のアイテムがあればコピー・複製・削除が有効。「貼り付け」は常に有効。単一選択時のみ「名前変更」「シーン切り替え」等の単体操作も有効。

ペースト時の命名規則は複製と同じ generateDuplicateName を適用（BGM以外）。

## アニメーション画像の継続再生

アニメーション画像（GIF/WebP/APNG）はシーン遷移をまたいで再生を継続する。

DomObjectOverlay で `generateStableKeys` 関数を使い、`type + image_url + 座標の近接性（greedy matching）` で React の key を割り当て。key が同一の DOM はリマウントされないため、アニメーションが継続。sceneId は key に含めない（含めるとシーン切替でリマウントされてしまう）。

blobCache は refCount ベース管理で、シーン遷移後も即 revoke せず 200ms 遅延 revoke。blobCache は画像の Blob を保持（fetch 省略 & メモリ管理）、表示用 blob URL はコンポーネントごとに毎回 `URL.createObjectURL` で新規生成し、unmount 時に revoke する。
