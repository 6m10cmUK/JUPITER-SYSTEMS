# チャット

リアルタイム メッセージ・ダイスロール・マークアップ対応。チャンネル分割。

### メッセージ送信・表示

ChatInputPanel で送信。sender_name / sender_uid / sender_avatar（URL）を記録。message_type は 'chat' / 'dice' / 'system'。senderName は localStorage で前回使用者保存。

チャットログ表示時、マークアップ処理：
- **太字**
- *イタリック*
- ~~打消し~~
- <color=#ff0000>色付き</color>

### ダイスロール

チャットを BCDice API（`https://bcdice.onlinesession.app/v2/game_system/{system}/roll`）に送信して結果を取得。結果を「ダイスロール」タイプ message として送信。ゲームシステムはルーム設定の dice_system を使用（デフォルト: DiceBot）。

BCDice API 送信前に、チャットパレットのテンプレート変数（`{ラベル名}`）を送信者キャラクターのステータス・パラメーター値で展開する。キャラクター未選択時は展開せずそのまま送信（BCDice が解釈できなければ通常チャットとして送信）。

秘密ダイス（BCDice の `secret` フラグ）に対応。秘密ダイス時は message_type='secret_dice' で1メッセージのみ INSERT する。RLS により送信者のみが SELECT 可能。他ユーザーへの通知はクライアントサイド Broadcast（content なし）で配信し、受信側はダミーメッセージ「シークレットダイス」をローカルに表示する。Broadcast 通知は localStorage にも保存され、リロード後も復元される。送信者には結果とともに公開アイコン（MessageSquareShare）が表示され、クリックすると message_type が 'dice' に UPDATE されて全ユーザーに結果が公開される。オープン時に localStorage の通知も自動削除される。

### チャンネル

デフォルトチャンネルは「メイン」「情報」「雑談」の3つ（UI定数として固定）。ユーザーがカスタムチャンネルを追加可能。channel_id で message 紐付け。allowed_user_ids で表示制限（共有範囲制御）。

### 展開ボタン

チャット入力欄下部の「展開」アイコン（Maximize2）で全画面エディタ表示。テキスト同期。

### スクロール・履歴

チャットログは最新200件を初期表示。上端までスクロールすると IntersectionObserver で自動検知し、D1 Worker API から過去ログを追加取得（1回200件）。取得中はスクロール位置を保持。

## チャットパレットパネル

キャラクターごとのチャットパレットを一覧表示し、テンプレートを素早く送信するパネル。ChatPaletteDockPanel として dockview に登録。

### 表示内容

各キャラクターのチャットパレット（chat_palette フィールド）を改行区切りでボタン一覧として表示。

### 操作

各行の左アイコン（Send）クリック：そのテキストを resolveTemplateVars でキャラクターのステータス・パラメーター値に変数展開して即チャット送信。

各行の右テキスト部分クリック：テキストをチャット入力欄に挿入（送信前に編集可能）。

## 入力サジェスト

チャット入力中にチャットパレットの候補をサジェスト表示。

入力中、全キャラクターの chat_palette 内容に対して部分一致で候補をリアルタイム検索。サジェストリストはカーソル位置（入力中の行）を基準にオーバーレイ表示。IME 入力中（変換中）はサジェストを更新しない。Arrow keys で候補ハイライト移動、Tab / Enter で選択・入力欄に反映。確定後はサジェストが閉じ、次の入力まで再表示しない。

## 入力パネル詳細

ChatInputPanel の詳細機能。

### テキスト修飾

入力欄上部のツールバーで以下のインライン修飾を適用。

太字（**テキスト**）

斜体（*テキスト*）

打消し線（~~テキスト~~）

見出し（# テキスト）

色付き（<color=#rrggbb>テキスト</color>）

### 送信者設定

キャラクタードロップダウンでキャラクター選択（そのキャラ名・アバターで送信）。

直接テキスト入力でも送信者名を指定可能。

### チャンネル設定

チャンネルドロップダウンで送信先チャンネルを選択。

## ログパネル詳細

ChatLogPanel の詳細機能。

### メッセージ種別と表示

chat：通常メッセージ。送信者名・アバター・テキスト表示。

dice：ダイスロール結果。成功は緑、失敗は赤でハイライト。

system：システム通知（入退室等）。グレー表示。

### 未読表示

未読メッセージがある場合、チャットパネルタブに赤ドット表示。

### チャンネルタブ

固定 3 チャンネル（メイン・情報・雑談）+ カスタムチャンネル。

カスタムチャンネルはタブ間でドラッグ&ドロップで並び替え可能。

### ログ出力

チャットログを HTML 形式でエクスポート可能。
