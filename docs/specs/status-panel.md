# ステータスパネル

全キャラクターのステータス・イニシアチブを一覧表示するパネル。StatusDockPanel として dockview に登録。

## 表示内容

キャラクター一覧をイニシアチブ値（initiative）降順でソートして表示。各キャラクターのステータス値を StatusBar コンポーネントで表示。

## 操作

ステータス値の変更は左ドラッグ（NumberDragInput）で操作可能。Blender 風のドラッグ操作で直感的に値を編集。イニシアチブの▲▼ボタンは廃止。

## 表示フィルタ

is_hidden_on_board: true のキャラクターはステータスパネルに表示しない。board_visible: false のキャラクターもステータスパネルに表示しない。盤面に表示されていないキャラクターのステータスは管理不要という設計方針。

## レスポンシブレイアウト

パネル幅に応じてキャラクターカード列数が自動調整される。各キャラクターカードのサイズを基準に、パネル幅内に収まる最大列数を動的に計算。画面リサイズ時にリフローする。

## プライベート設定

is_status_private が true のキャラクターのステータスは「?」として表示（owner のみ実値確認可）。
