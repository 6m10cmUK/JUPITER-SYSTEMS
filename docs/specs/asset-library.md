# アセットライブラリ

画像・音声ファイルを一元管理するモーダル。AssetLibraryModal として実装。

## タブ

画像タブ：画像ファイル一覧、アップロード・URL 入力・タグ付け・検索（名前/タグ）。

音声タブ：音声ファイル一覧、アップロード・URL 入力・YouTube URL 入力・タグ付け・検索（名前/タイトル/タグ）。

## アップロード方式

### 画像
ファイルアップロード → Cloudflare R2 に保存。
ファイルのドラッグ&ドロップ、あるいは「アップロード」ボタンからファイル選択に対応。
複数ファイルの同時アップロードにも対応。

ファイルサイズ上限：5MB。超過時はエラートースト表示。

### 音声
URL 直接入力（Dropbox・Google Drive 共有リンクは自動正規化）。
YouTube URL 入力。

YouTube 試聴は react-youtube コンポーネントに統一。YouTube URL からタイトルを自動取得する際は oEmbed API を利用。

## 検索・フィルタ

検索バーは AdComboBox（mode="single"）で実装。テキスト入力による部分一致検索と、既存タグ候補のドロップダウン選択を兼ねる。

検索対象はファイル名・タイトル・タグ。タグ候補は登録済み全アセットのタグから自動収集。

## タグ管理

各アセットにタグを複数付与可能。タグ一覧から一括絞り込み。
アセット登録時に、ルーム名のタグを自動付与。

### タグ編集 UI

アセットのタグ表示部分をクリックするとインライン編集モードに切り替わる。

編集 UI は AdComboBox（mode="multi"）を使用し、以下の操作が可能:
- 既存タグ候補からのドロップダウン選択
- 自由入力による新規タグ追加
- チップ表示された各タグの ✕ ボタンで個別削除

候補リストには、同ユーザーの全アセットに付与済みのタグが表示される（現在編集中のアセットに既に付いているタグは候補から除外）。

編集確定は「保存」ボタンまたは外側クリック。「取消」で編集前の状態に戻す。

### AssetPicker 経由のタグ自動付与

AssetPicker（プロパティ編集からアセットライブラリを開くコンポーネント）経由でアセットを登録した場合、呼び出し元の種別に応じたタグを追加で自動付与する。

| 呼び出し元 | 自動付与タグ |
|-----------|------------|
| 背景画像選択 | 背景 |
| 前景画像選択 | 前景 |
| キャラクター画像選択 | キャラクター |
| オブジェクト画像選択 | オブジェクト |
| カットイン画像選択 | カットイン |

ルーム名タグと種別タグは重複しない限り両方付与される。アセットライブラリを直接開いた場合（ツールバーボタン）はルーム名タグのみ。

自動付与はアセットの新規登録時（ファイルアップロード・URL 追加の両方）に適用される。URL 追加時も必ず DB にアセットとして登録し、タグを付与する。

## AssetPicker 経由での利用

背景・前景・キャラクター・オブジェクト等、任意のプロパティ編集からアセットライブラリを開いた場合（AssetPicker コンテキスト）、呼び出し元に関わらず以下の共通の振る舞いをする。

### ドラッグ&ドロップによる画像追加
アセットライブラリ上にファイルをドラッグ&ドロップした場合、アセット登録と選択（呼び出し元への適用）を一括で行う。
具体的には、アセットへの追加完了後、そのアセットを自動選択状態にし、呼び出し元に即座に反映する。
ユーザーが「DnDで画像を入れたのに何も起きない」状態にしてはならない。

### URL 追加
AssetPicker 経由で URL を追加した場合も、アセットとして DB に登録してからそのアセットを選択する。URL を直接渡して DB 登録をスキップしない。

### 選択操作
既存アセットのクリックで即選択、呼び出し元に反映。これは現行仕様通り。
