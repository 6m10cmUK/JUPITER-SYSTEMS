# キーボードショートカット

ボード・パネル操作の高速化。

## ボード操作

Ctrl+Z：Undo
Ctrl+Y / Ctrl+Shift+Z：Redo
Delete：選択オブジェクト削除（確認ダイアログ）
Ctrl+C：選択オブジェクトコピー
Ctrl+V：ペースト
Ctrl+D：選択オブジェクト複製

## パネル操作

Ctrl+C（LayerPanel）：選択オブジェクト / シーン / キャラクター コピー
Ctrl+D（LayerPanel）：複製
Ctrl+V（LayerPanel）：ペースト

Delete（ScenePanel）：選択シーン削除（複数選択時も一括）
Delete（CharacterPanel）：選択キャラ削除

Delete（BgmPanel）：選択BGM削除
Delete（ScenarioTextPanel）：選択テキスト削除

Enter（ChatInputPanel）：メッセージ送信 / Shift+Enter：改行

## 条件付け

エディタ入力中（INPUT / TEXTAREA / contentEditable）の場合、ショートカット無効化。削除系操作は確認ダイアログ要求。
