# 複数選択・ドラッグ&ドロップ詳細

各パネルでの複数選択操作とドラッグ&ドロップの詳細仕様。

## 選択操作（全パネル共通）

単体クリック：単一選択。

Shift+クリック：範囲選択。

Ctrl+クリック：個別追加/解除（トグル）。

## ScenePanel

複数選択時、Delete で一括削除（確認ダイアログ）。

複数選択時、右クリック「複製」で一括複製。

## ObjectLayerList（レイヤーパネル内オブジェクト一覧）

複数オブジェクト選択状態でドラッグ：選択中の全オブジェクトを一括移動。

ドラッグ対象が未選択オブジェクトの場合：単一選択に切り替えてからドラッグ。

background：位置固定のため DnD 不可。

foreground：DnD 不可（z 順変更のための DnD は制限あり）。

characters_layer 内のキャラクター：内部でのみ DnD で並べ替え可能。

## CharacterPanel

複数選択時、Delete で一括削除。

ドラッグ&ドロップでキャラクター表示順を変更（ボード上の z 順とは独立）。
