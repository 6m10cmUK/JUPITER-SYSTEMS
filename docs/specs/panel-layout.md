# パネルレイアウト管理（dockview）

DockLayout.tsx で dockview ライブラリを使い、柔軟なパネル配置を実現。

## レイアウト保存

パネルの配置・サイズ変更を 300ms debounce で localStorage に自動保存。

ページリロード後もレイアウトを復元。

## パネル操作

フロート化：パネルヘッダーの PictureInPicture2 アイコンで独立ウィンドウとして切り離し。

最小化：パネルを折りたたみ表示。

ドッキング：フロートパネルをドラッグしてドックに戻す。

## デフォルトレイアウト

ロール（owner / sub_owner / user / guest）ごとに初期パネル配置を定義。

保存済みレイアウトがない初回アクセス時に適用。

## 幅制約

Board パネルは幅可変（残りスペースを占有）。

その他パネル（サイドバー系）は固定幅制約。
